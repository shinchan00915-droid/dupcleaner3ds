3DS 중복 게임 정리기 (DupCleaner3DS)

[빌드 방법 - GitHub, 설치 필요 없음]
1. github.com 에서 새 저장소(repository) 만들기
2. 이 zip 안의 파일 전부 업로드 (source 폴더, .github 폴더, Makefile, icon.png 포함)
3. Actions 탭 -> Build 3dsx -> 초록색 체크 뜨면 클릭 -> 맨 아래 Artifacts 의 DupCleaner3DS 다운로드
4. zip 안의 DupCleaner3DS.3dsx 를 SD카드 /3ds/ 폴더에 넣고 Homebrew Launcher 로 실행

[빌드 방법 - 내 PC]
devkitPro(3ds-dev, 3ds-portlibs) 설치 후 이 폴더에서 make

[조작]
↑↓ 이동 / L,R 페이지 / A 선택 / X 삭제 / Y 중복만-전체 / SELECT 세이브삭제 ON-OFF / B 선택해제 / START 종료
